# 生活动态

一款跨平台生活记录应用，本地数据优先，通过 WebDAV 实现多端云同步，支持图片、视频、标签和加密存储。

# 设计目标
APP支持用户本地发布动态，支持图片视频两类各种格式的文件上传，文件上传是将数据拷贝到APP内部私有空间，上传后可由用户选择，是否进行云端同步，与云端数据结合。
APP内部数据管理和云端同步功能参考思源笔记的设计模式，可以从github上面下载源码分析查看。
设计模式参考思源笔记，本地操作和云同步是分开的，不要相互影响，且云端是要有锁管理的，避免多端数据冲突，还有有快照等。
数据加密传输到云端，添加一个传输原始数据的开关。
我们的APP没有复杂的数据库管理，文件的存储模式也是参考思源笔记，所有文件存到一个内部目录，然后使用都是引用的方式。

## ✨ 核心功能

- **动态发布** — 文字 + 多图 + 视频，支持 `#标签` 自动识别，发布即刻完成（本地操作）
- **数据同步** — 本地完整存储数据，后台异步与 WebDAV 双向同步，多端数据一致
- **端到端加密** — 媒体文件和数据文件 AES 加密后存储
- **多端支持** — Android、iOS、Linux、Web 四端统一
- **用户资料同步** — 头像和昵称存储在 WebDAV，新设备自动同步
- **全屏图片查看** — 双指缩放、左右滑动、下滑关闭，支持加密图片解密
- **快照恢复** — 每次同步自动创建快照，保留最近 10 个，支持数据恢复

## 🏗️ 架构设计

### 核心模块分离

```
┌─────────────────────────────────────────────────────┐
│                     UI 层                            │
│  发布/编辑/删除 → 操作本地数据（毫秒级，无网络等待）    │
└────────────────────┬────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────┐
│               FeedBloc（本地数据操作）                │
│  · 发布 → 复制媒体到 local_data/media/               │
│  · 保存 data.json 到 local_data/                     │
│  · 标记 pendingSync                                  │
└────────────────────┬────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────┐
│         CacheService（后台同步模块）                  │
│  · 推送本地数据 → WebDAV（fire-and-forget）          │
│  · 拉取 WebDAV → 合并本地（远程为基准+本地独有）      │
│  · 快照管理（保留最近 10 个）                         │
└─────────────────────────────────────────────────────┘
```

### 数据流

```
发布动态 → 保存本地 → 立即返回 → UI 秒出
              │
              ▼
       pendingSync = true
              │
              ▼
    ┌─────────────────────┐
    │  后台异步推送 WebDAV  │  ← 不阻塞 UI
    └─────────────────────┘
              │
              ▼
    ┌─────────────────────┐
    │  后台拉取 WebDAV     │  ← 合并多端数据
    │  + 合并本地独有帖子   │
    └─────────────────────┘
```

## 🛠️ 技术栈

| 组件 | 说明 |
|------|------|
| 状态管理 | flutter_bloc |
| 视频播放 | media_kit（自带 mpv 解码器，跨平台统一） |
| 图片查看 | photo_view + cached_network_image |
| HTTP 客户端 | dio（WebDAV 协议） |
| 本地存储 | path_provider + json |
| 加密 | AES (encrypt 包) |

### WebDAV 目录结构

```
/flutter_media_manager/
├── data.json          # 动态数据（加密）
├── profile.json       # 用户资料
├── avatar.ext         # 头像文件
├── media/             # 媒体文件（加密）
│   ├── IMG_001.jpg
│   ├── VID_002.mp4
│   └── ...
└── raw/               # 原始数据（可选，不加密副本）
```

### 本地数据目录（APP 私有空间）

```
local_data/
├── data.json          # 本地动态数据
├── media/             # 本地媒体文件（不加密）
│   ├── IMG_001.jpg
│   ├── VID_002.mp4
│   └── ...
└── snapshots/         # 数据快照（保留最近 10 个）
    ├── data_1234567890.json
    └── ...
```

## 🚀 快速开始

### 环境要求

- Flutter 3.44.x (stable channel)
- Dart 3.x
- Android: JDK 17 + Android SDK
- iOS: Xcode 15+ (仅 macOS)
- Linux: `ninja-build` + `libgtk-3-dev` + `libasound2-dev` + `libmpv-dev`

### 编译运行

```bash
# 获取依赖
flutter pub get

# Linux
flutter run -d linux
flutter build linux --release

# Android
flutter build apk --release

# iOS (需 macOS)
flutter build ios --release --no-codesign

# Web
flutter run -d chrome
```

### Linux 构建依赖（仅构建时需要）

```bash
sudo apt install libasound2-dev libmpv-dev libmpv2
```
